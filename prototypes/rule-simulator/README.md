# 拿破仑卡牌游戏规则模拟器

> Game Studios location: `prototypes/rule-simulator/`

一个用 Python 写的命令行模拟器，验证拿破仑战争主题 CCG 的核心规则是否成立。
**目的**：在投入 Unity 开发之前，用 4 个文件先证明规则不卡死、节奏合理、阵营有差异。

---

## 为什么要先做模拟器

如果三线战场 + 军令资源 + 步骑炮克制在纯文字模拟中跑不通，做成 Unity 也救不回来。
模拟器跑 100 局只要几秒，比 Unity 上手测试快 1000 倍。

---

## 文件结构

| 文件 | 作用 |
|------|------|
| `cards.py` | 卡牌定义 + 法/普两个阵营的牌库（每方 30 张） |
| `game_state.py` | 玩家、战场、单位的运行时状态 |
| `combat.py` | 战斗系统、克制规则、目标选择 |
| `ai.py` | 简单启发式 AI（不是强 AI，只是不卡死） |
| `game.py` | 主对局循环，跑单局 |
| `batch_sim.py` | 批量模拟，跑 N 局看统计 |
| `experiments.py` | 对照实验：先后手、HQ 血量、起手牌 |
| `exp_compensation.py` | 后手补偿方案 A/B/C/D/E 对比 |

---

## 怎么跑

```bash
# 跑一局，看完整对战日志
python game.py

# 跑 100 局，看胜率/回合数/活跃度统计
python batch_sim.py 100

# 跑对照实验（先后手对称性、HQ 血量、起手牌数）
python experiments.py

# 跑后手补偿方案对比
python exp_compensation.py
```

需要 Python 3.9+，无任何外部依赖。

## 当前规则配置

| 参数 | 值 |
|------|-----|
| HQ 血量 | 25 点 |
| 起手手牌 | 4 张（后手再 +1） |

## 已验证的关键发现（n=100~400 局）

### ✅ 节奏健康
- 平均 **15.1 回合**结束，中位数 15 回合
- 91% 的对局在 11-20 回合之间
- **0% 超时率**（30 回合内全部分胜负）
- 推荐 HQ 血量调到 **20**（平均回合数会降到 14，节奏更紧凑）

### ⚠️ 先手优势偏大（默认配置 57% 镜像胜率）
**最优补偿：后手起手 +2 张牌（共 6 张），不要给军令补偿**
- A：后手 +1 牌（当前）→ 57.2% 先手胜率（偏高）
- **B：后手 +2 牌 → 51.7% 先手胜率** ✅ 推荐
- C：后手 +1 军令 → 45.8%（反向过补）
- D：后手 +1 牌 +1 军令 → 42.8%（明显过补）

### ✅ 阵营差异化成立
- 法 vs 普：法 56% / 普 44%（法略强，符合"高数值精锐"定位）
- 普 vs 法：普 47% / 法 53%（即便先手也只有 47%，说明普本身略弱）
- **结论：阵营之间有差异但不失衡，符合预期**

### ✅ 三线战场不会卡死
- 散兵线作为前压区，平均场上有 18-19 个单位部署
- 步兵从主力线前压到散兵线的机制能正常运作
- 炮兵远程打 HQ 受到"敌方主力线为空"限制，不会出现首回合直击

### ⚠️ 后期炮兵 ping HQ 偏强
- 详细对局日志中观察到：后期双方主力线被消耗光后，炮兵会持续打 HQ 直到结束
- **建议**：未来加入"HQ 受到伤害后获得 1 回合护盾"机制，或者炮兵远程打 HQ 需要消耗额外军令

## 兵种克制实现（当前数值）

| 攻击方 → 防御方 | 倍率 | 关键词触发 |
|---|---|---|
| 骑兵 → 散开步兵 | ×2 | 无"结阵" |
| 骑兵 → 方阵步兵 | ÷2 | 有"结阵"，且方阵全额反击 |
| 炮兵 → 密集步兵 | +1 | 攻击 INFANTRY/GUARD 时 |
| 远程炮兵 | 0 反击 | 有"远程"关键词 |
| 散兵闪避 | 0 伤害 | 一次性，对非炮兵生效 |
| 齐射 | +1 先制 | 攻击前先造成 1 点 |
| 突破 | 溢出打 HQ | 杀死目标后 |

## 模拟器没解决的问题（需要真人测试）

1. **可玩性**：AI vs AI 跑 15 回合不代表玩家觉得 15 回合好玩
2. **学习曲线**：三线 + 关键词 + 兵种克制，新手能不能 3 局上手
3. **决策深度**：当前 AI 是简单贪心，不能反映高水平玩家的博弈
4. **卡组多样性**：每方只有 30 张固定牌，没有牌组构筑维度
5. **指令卡 / 事件卡**：当前完全没实现（如焦土、齐射命令、海军支援等）

这些都需要 Unity 原型 + 真人测试来回答。
