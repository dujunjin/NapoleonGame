## 三类产出

### 1. 规则模拟器（Python）

跑命令行批量对战，验证机制、节奏、阵营平衡。

```bash
# 跑一局详细日志
python3 game.py

# 跑 200 局批量统计
python3 batch_sim.py 200

# 三阵营生态测试
python3 ecosystem_test.py 200
```

**当前数据基线**（健康）：
- 平均 13-15 回合分胜负
- 0% 超时
- 三阵营综合胜率：法 52.6% / 普 52.8% / 俄 44.6%
- 镜像对决先手胜率：49-52%（先后手平衡）

**当前核心调参**：
- 手牌 <=2 时，回合开始抽 2 张；否则抽 1 张
- 军令 6 点前每回合 +1；达到 6 后每 2 回合 +1，封顶 10
- 战斗日志会明确标出阵亡单位，方便用 viewer 复盘

### 2. 对局可视化（HTML）

打开 `viewer.html` 即可在浏览器中查看 AI 对局回放，支持：

- 三种典型对决预设（下拉框切换）
- 单步前进 / 后退 / 自动播放
- 三线战场可视化，单位卡片实时数值
- 完整对战日志（部署、攻击、自残、光环触发）
- 海报化复古拿战美术风格

```bash
# 生成新对局数据
python3 export_match.py FRANCE RUSSIA 42      # 法兰西先手 vs 俄罗斯后手，种子 42
python3 export_match.py PRUSSIA RUSSIA 7      # 普鲁士 vs 俄罗斯
python3 export_match.py FRANCE PRUSSIA 10     # 法兰西 vs 普鲁士
```

⚠️ **注意**：浏览器双击打开 `viewer.html` 时，加载本地 JSON 可能被 CORS 限制。如果显示"无法加载"，启动本地服务器：

```bash
cd prototypes/card-battle-sim
python3 -m http.server 8000
# 然后访问 http://localhost:8000/viewer.html
```

### 3. 纸牌原型 PDF

`napoleon_cards.pdf`：A4 横向，每页 8 张标准扑克牌大小（63×88mm）的卡。

- 共 16 页：3 阵营牌库（每方 30 张）+ 卡背 + 规则速查
- 海报化设计：阵营色（法兰西蓝 / 普鲁士黑 / 俄罗斯墨绿）+ 复古羊皮纸底
- 卡面信息：费用印章、兵种圆章、名称、关键词描述、攻防数值
- 沿虚线剪裁即可手玩

```bash
# 重新生成 PDF
python3 generate_pdf.py
```

**打印建议**：
- A4 横向、无缩放打印
- 普通打印纸即可（建议 100g 以上更挺括）
- 想做得正式：双面打印（卡背页）+ 卡牌切刀
- 或：直接装入透明卡套保护，可重复使用

## 下一步建议

到这里规则原型可信度已经够进入真人测试了。建议：

### 1. 打印 PDF，叫上 1-2 个朋友手玩 5 局

5 局后能立刻知道：规则是否清晰、玩起来是否好玩、哪些关键词反人类。
比再加一个阵营有用 10 倍。

### 2. 真人测试中重点观察

- 新手第几局开始不需要查规则速查？
- 三线 + 前压机制能不能 3 局上手？
- 自残机制（俄罗斯）的体感是"史诗反击"还是"无力挣扎"？
- 第 8 回合左右是否有"决策瓶颈"（炮兵问题）？

### 3. 真人反馈后再决定

- 如果反馈"基础规则成立但缺乏深度" → 加事件卡 / 指令卡
- 如果反馈"规则太复杂" → 砍关键词，回到 4-5 个核心
- 如果反馈"3 阵营够多但单调" → 加第 4 阵营（英国或奥地利）

**不要做的事**：
- 不要在 Python 里继续加新阵营。代码 ≠ 玩法验证。
- 不要急着上 Unity。规则原型在纸上就能验证完。
