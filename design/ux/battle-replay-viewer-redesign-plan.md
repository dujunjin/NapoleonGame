## 1. 问题陈述

当前 viewer.html (~2145行) 是功能完整的回放工具，但存在以下问题：

- **视觉平淡**：暗紫+金色主题，缺少拿破仑战争的史诗氛围
- **信息密度过高**：顶部控件栏、玩家条、阶段条、操作面板、历史表格堆叠，视觉疲劳
- **交互冗余**：7个播放按钮 + 下拉菜单 + 过滤器芯片 + 滑块，控件过多
- **缺少动效**：攻击箭头为静态SVG，无震屏、无浮动伤害、无转场
- **历史面板为表格**：不够直观，缺少时间线叙事感

---

## 2. 设计目标

| 目标 | 衡量标准 |
|------|----------|
| 沉浸感 | 玩家感觉在观看一场真实的拿破仑战役 |
| 史诗感 | 攻击、部署、推进有视觉冲击力 |
| 简单易上手 | 5秒内理解当前战局；核心操作不超过3种手势 |
| 功能完整 | 所有现有功能保留（JSON加载、键盘控制、攻击箭头、历史记录等） |

---

## 3. 视觉重设计方向

### 3.1 色彩体系替换

| 用途 | 旧值 | 新值 | 理由 |
|------|------|------|------|
| 背景深色 | `#1a1a2e` (暗紫) | `#0a0c14` (深空蓝黑) | 更沉稳，模拟夜间战场 |
| 表面色 | `#22223a` | `#0f1220` / `#1a1f35` | 暗石板蓝，军事感 |
| 强调色 | `#c9a84c` (金色) | 保留，增加 `#e0c060` 发光变体 | 黄铜指挥色，不变 |
| 伤害色 | `#c2552c` (橙红) | `#8b1a1a` → `#c23030` (血红梯度) | 更沉重的战争感 |
| 阵营色 | 不变 | 不变 | 已有辨识度 |

### 3.2 纹理与氛围

- **背景层**：CSS军事地图网格 (60px间距淡金线) + 径向渐变模拟烛光暗角
- **面板**：半透明暗色 + 微妙噪点纹理
- ~~烟雾粒子~~ → **延期**：低功能价值，增加性能/无障碍风险
- ~~战争迷雾~~ → **延期**：回放/调试视图不应遮挡信息

> **设计原则**（对齐 `docs/product/kards-inspired-battle-ui-design.md:472-478`）：
> 优先调试清晰度 > 电影化展示。氛围效果纯装饰，不得降低可读性。

### 3.3 字体

```css
--font-display: "Georgia", "Noto Serif SC", serif;  /* 标题 */
--font-body: "Hiragino Sans", "PingFang SC", sans-serif;  /* 正文 */
--font-mono: "SF Mono", "Menlo", monospace;  /* 数据 */
```

## 4. 布局重构

### 4.1 当前布局 (问题)

```
[标题栏]
[控件栏: 7按钮 + 下拉 + 过滤器 + 滑块 + 速度]
[玩家条 x2]
[阶段条]
[战场区域]
[操作面板]
[结果横幅]
[历史表格]
```

→ 8个堆叠区域，视觉碎片化

### 4.2 新布局方案

```
┌──────────────────────────────────────────────────┐
│              标题横幅 (阵营 vs 阵营)              │
├──────────────────────────────┬───────────────────┤
│                              │                   │
│     战场主区域 (75%)          │  时间轴侧栏 (25%) │
│     HQ + 5条战线              │  (事件卡片流)      │
│                              │                   │
├──────────────────────────────┴───────────────────┤
│         当前操作摘要条带（始终可见）               │
├──────────────────────────────────────────────────┤
│           底部浮动播放栏 (固定)                    │
└──────────────────────────────────────────────────┘
```

**变化**：
- 控件栏 + 玩家条 + 阶段条 + 操作面板 → 合并到底部播放栏 + 战场内嵌信息
- 历史表格 → 时间轴侧栏（事件卡片流）
- 结果横幅 → 居中覆盖层

### 4.3 HQ 指挥部

旧：纯数字显示
新：**健康条 + 数字**组合

```
敌方指挥部  ████████░░░░  11/14  ⚠ 威胁3
```

- 血条使用血红渐变，低于35%脉冲闪烁
- HQ受击时面板震动+红光

### 4.4 底部播放栏

浮动毛玻璃栏，替代原顶部控件栏：

```
[对局选择] [⏮][◀◀][◀][ ▶ 播放 ][▶][▶▶][⏭] ──●────── 1x [☰]
```

- 进度条可点击跳转，带回合刻度标记
- 速度按钮点击循环 0.5x→1x→2x→4x
- 移动端：☰ 按钮呼出时间轴侧栏

### 4.5 时间轴侧栏

替代历史表格，按回合分组的垂直事件卡片流：

```
── 回合 1 ──
  ▶ 部署 线列步兵 → 主力 槽位0
  ▶ 部署 散兵 → 散兵线
  ⚔ 攻击 → 3伤害 💀
── 回合 2 ──
  ⇒ 推进 散兵线
  💥 HQ直击 → 2伤害
```

- 点击卡片跳转步骤
- 当前步骤金色左边框高亮
- 过滤器保留（全部/部署/攻击/事件）

## 5. 动效方案

### 5.1 屏幕震动

| 事件 | 震动类型 | 时长 | 备注 |
|------|----------|------|------|
| 普通攻击 | `screen-shake` 轻震 | 0.4s | 仅在不降低可读性时启用 |
| HQ直击 | `screen-shake-heavy` 重震 | 0.6s | 同上 |
| 击杀 | 无额外震动（已有死亡动画） | - | - |

> 震动作用于 `#battleboard` 容器，SVG 箭头在独立层不受影响。
> `prefers-reduced-motion` 时全部禁用。

### 5.2 浮动伤害数字

- 攻击时从目标位置向上飘散红色 `−3` 文字
- 反击时从攻击方位置飘散
- 1.2s 后淡出消失
- `prefers-reduced-motion` 时禁用

### 5.3 攻击箭头增强

- 旧：静态实线SVG
- 新：虚线脉冲流动 (`stroke-dasharray` + `animation`)

### 5.4 单位卡片动画

| 状态 | 动画 |
|------|------|
| 部署 | 从底部弹入 (cubic-bezier overshoot) |
| 攻击源 | 黄铜发光脉冲交替 |
| 攻击目标 | 红色震动 0.3s |
| 受伤 | HP数字背景闪红 |
| 阵亡 | 灰化 + 虚线边框 |
| 动摇 | 轻微颤抖循环 |

### 5.5 结果结算

- 居中覆盖层，金色光芒卡片
- `scale(0.7)→scale(1)` 弹入动画

## 6. 交互简化

### 6.1 控件精简

| 旧控件 | 新控件 | 变化 |
|--------|--------|------|
| 7个播放按钮 | 7个按钮（保留在底栏） | 位置移至底部 |
| 速度下拉菜单 | 速度按钮（点击循环） | 减少一次点击 |
| 过滤器芯片 x5 | 过滤器芯片 x5（全部保留，在侧栏） | 保留 HQ 过滤 |
| 时间轴滑块 | 进度条（可点击） | 更直观 |
| 匹配下拉 | 保留在底栏左侧 | 不变 |
| 原始日志切换 | 保留在侧栏底部 | 不变 |

**当前操作摘要**：必须始终可见。保留在战场下方，作为战场与时间轴之间的独立条带，始终显示当前回合/阵营/动作/摘要。

### 6.2 移动端适配

- ≤1000px：时间轴侧栏隐藏，☰ 按钮呼出滑出面板
- ≤600px：更紧凑的卡片和按钮尺寸

## 7. 不变项（必须保留）

- JSON 加载和匹配切换
- 键盘控制 (←→ Space Home End)
- 5条战线 + 散兵线状态标签
- 攻击箭头 (SVG)
- 单位卡片信息（费用/名称/类型/关键词/攻击/HP）
- 单位 tooltip（hover 显示关键词解释）
- 原始日志访问
- `prefers-reduced-motion` 无障碍
- 焦点可见性 (`:focus-visible`)
- aria-label / aria-live
- 响应式布局（1280px / 390px）
- 单文件 HTML，无框架，无外部依赖

## 10. 风险

| 风险 | 缓解 |
|------|------|
| CSS粒子影响性能 | 限制20个，`will-change`优化，移动端可减半 |
| 震屏动画与攻击箭头冲突 | 震屏作用于battleboard容器，箭头在SVG层 |
| 侧栏在小屏占空间 | 移动端隐藏为滑出面板 |
| 函数名变更破坏测试 | 保持 `findUnitElementForAttack` 等关键函数名 |
