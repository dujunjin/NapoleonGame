# 拿破仑战争主题卡牌游戏 MVP 调研提示词（PC 优先）

## 项目定位

开发一款受 *Kards: The WWII Card Game* 启发的策略卡牌游戏（CCG）。MVP 阶段聚焦：

- **单一时代**：拿破仑战争时期（1789 革命爆发 - 1815 滑铁卢），后续 DLC 再向前/后扩展
- **平台**：PC 优先（Steam 首发），后续考虑移动端移植
- **核心创新**：多势力交战 + 行动点出牌 + 海报化美术
- **对标体量**：Kards 级别（Steam 同时在线 1k-3k，月活 10w+ 量级）

请基于以上定位，输出 4 周内可完成的立项调研。**结论必须明确，不接受"看情况"答案。**

## 调研维度

### 一、Kards 深度拆解（必须，占调研 30% 工作量）

**目标**：吃透 Kards 的每一个设计决策及其后果。

**1. 机制层**
- Kredits 系统完整规则：初始值、每回合增长、上限、特殊获取手段
- 双国家牌组（Allies）的组合规则、主国 vs 次国卡比例限制
- Frontline / Backline 部署逻辑、攻击优先级、突破（Smash）机制
- HQ 血量、直接攻击触发条件
- 单位类型（Infantry / Tank / Fighter / Bomber / Artillery）的克制系数
- 关键字技能列表（Blitz / Guard / Smokescreen / Ambush 等）及使用频率
- Order（命令卡）与 Unit 的占比、单回合可打出数量

**2. 阵营层**
- 7 个国家阵营的差异化定位（USA = 量产 / Soviet = 消耗 / Germany = 精英 ...）
- 每个阵营标志机制
- 平衡历史：哪些阵营长期 OP、哪些被边缘化、版本变迁

**3. 商业与运营**
- 卡包结构（每包张数、稀有度概率）
- 战令（Battle Pass）内容与定价
- 入门玩家解锁全卡所需时间（F2P 友好度）
- 赛季更新节奏、新阵营/扩展包推出频率
- DLC 国家定价策略

**4. 数据与口碑**
- Steam 评测正负面关键词（拉 1000+ 评论做词频分析）
- SteamDB 同时在线趋势（上线至今）
- Reddit r/KardsTheGame 高赞讨论主题
- 玩家流失主因（前 3 名）
- Discord 社区活跃度

**5. 借鉴与规避**
明确列出：
- 可直接借鉴的设计（10 条以上）
- 必须规避的坑（5 条以上）
- 可超越的弱点（5 条以上）

### 二、拿破仑时代设定研究（占 20%）

**1. 可玩势力候选**

候选清单（请评估并定稿 6-8 个 MVP 势力）：

| 势力 | 历史定位 | 机制方向候选 |
|------|----------|--------------|
| 法兰西第一帝国 | 攻击型主角 | 革命动员、纵队冲锋、军团荣誉 |
| 大不列颠 | 海权 + 殖民 | 海军压制、经济战、雇佣兵 |
| 普鲁士 | 改革型军国 | 散兵战术、参谋体系、爱国动员 |
| 俄罗斯帝国 | 消耗型大国 | 焦土、严寒加成、人海 |
| 奥地利帝国 | 多民族联盟 | 多兵种协同、防御反击 |
| 西班牙 | 游击战 | 非正规作战、宗教狂热 |
| 奥斯曼帝国 | 衰落巨人 | 旧式精锐 + 改革阵痛 |
| 波兰 / 莱茵邦联 | 仆从 / 卫星 | 可作为 DLC 储备 |

请给每个势力补全：
- 8-12 个代表兵种（轻步、线列、掷弹、骠骑、龙骑、胸甲骑兵、炮兵、近卫、海军、游击）
- 3-5 个标志性将领（拿破仑、惠灵顿、库图佐夫、布吕歇尔、内伊、达武等）
- 5-8 个关键战役/事件卡（奥斯特里茨、特拉法加、博罗季诺、半岛战争、莱比锡、滑铁卢等）
- 阵营被动机制（一句话）

**2. 历史考据要点**
- 拿战时期的兵种分类与交战方式（线列步兵 vs 散兵 vs 纵队）
- 兵种相克的真实历史依据（轻骑 vs 散兵、方阵步兵 vs 骑兵、炮兵 vs 密集步兵）
- 海战独立卡池还是融入主战场？（特拉法加、尼罗河战役不能缺席）
- 后勤、士气、天气这些"软系统"是否纳入卡牌机制

**3. 历史敏感性**
- 拿破仑、惠灵顿、库图佐夫等人物在欧洲各国的争议程度
- 西班牙游击战中的暴行如何处理（参考 Goya 画作）
- 海地革命、拿破仑奴隶政策是否触碰
- 是否做"半架空"处理（人物保留，部分历史事件虚构化）以规避争议

### 三、核心机制设计调研（占 25%）

**1. 行动点系统的拿战化包装**

候选命名：**军令（Orders）** / 战意（Morale） / 补给（Supply） / 鼓声（Drums）

请评估：
- 哪个最契合拿战军事文化？
- Kards 的 Kredits 曲线是否直接套用，还是改造？
- 是否引入"士气"作为副资源（高士气 = 步兵更勇猛 / 骑兵更敢冲）

**2. 战场结构**

候选方案：
- **A. 直接复用 Kards 的 Frontline / Backline**：上手成本最低，但缺乏差异化
- **B. 三线结构**：散兵线 / 主力线 / 后方（炮兵 + 后勤），更贴合拿战
- **C. 引入"地形"**：每局战场有地形特征（平原利骑兵、山地利散兵、城镇利防御）
- **D. 大地图 + 会战**：战略层抢城市/补给，战术层打牌

明确推荐一种，给出原型流程。

**3. 多势力对战的可行性（核心决策点）**

这是 MVP 阶段的最大风险。请重点回答：
- 是否在 MVP 中引入多方对战？还是 1.0 版本只做 1v1，多方做 1.5 版本？
- 调研 Artifact、Eternal、Hex 的多方对战为什么没跑通
- 桌游 Diplomacy、Twilight Imperium 的多方机制能否数字化
- 推荐方案：
  - 方案 A：MVP 只做 1v1（标准 + 征服模式），多方做赛季活动
  - 方案 B：MVP 包含 2v2 团队战（盟军 vs 法军），不做混战
  - 方案 C：MVP 直接做 3-4 人混战（高风险，高差异化）

**强烈倾向方案 A 或 B，请给出推荐理由**。

**4. 兵种克制矩阵**

请输出一张拿战兵种克制表，至少包括：
- 轻步 / 线列 / 掷弹 / 散兵
- 轻骑 / 龙骑 / 胸甲骑兵 / 哥萨克
- 步兵炮 / 骑炮 / 攻城炮 / 榴弹炮
- 战列舰 / 巡防舰

并标注每个克制关系背后的历史逻辑。

### 四、PC 端竞品与平台研究（占 10%）

**1. Steam 平台 CCG 现状**
- 近 3 年 Steam 上线的 CCG 列表及成绩（同时在线峰值、评测数）
- 头部：Marvel Snap（PC 版）、LoR、MTG Arena、炉石（非 Steam 但需对标）
- 中型：Kards、Gwent、Eternal、Mythgard
- 失败案例：Artifact、Faeria、SolForge

**2. PC 端 CCG 的差异化优势**
- 屏幕大、信息密度可以更高（vs 手游）
- Mod 社区潜力（参考 Slay the Spire）
- 直播友好（OBS 兼容、观战模式）
- 键鼠操作可支持更复杂的牌组构建工具

**3. Steam 发行策略**
- 抢先体验（Early Access）vs 直接 1.0 上线
- Demo / 试玩节参与
- 创意工坊（卡组分享、自定义事件）
- 成就系统设计

### 五、美术风格定位（占 10%）

**1. 拿战时期视觉资源库**

主要参考源：
- 同时代画家：Jacques-Louis David、Antoine-Jean Gros、Goya、Théodore Géricault
- 军事插画家：Édouard Detaille、Richard Knötel（拿战军装百科）
- 19 世纪石版画、铜版画
- 拿破仑帝国宣传海报

**2. 风格选项**
- **A. 写实油画风**（David / Gros 路线）：贵族感强，制作成本高，可能显沉闷
- **B. 海报化漫画风**（Kards 路线 + 拿战元素）：辨识度高，社区友好，**推荐起点**
- **C. 蚀刻版画风**（Goya《战争的灾难》路线）：极具时代感，但偏阴暗
- **D. 拼贴构成主义风**：实验性强，可能水土不服

请明确推荐 + 给出 5-10 张 Mood Board 参考图方向。

**3. 卡面布局**
- 数值位置（攻 / 血 / 费）—— 直接对标 Kards 还是创新？
- 阵营色方案（法 = 蓝白红 / 英 = 红金 / 普 = 黑银 / 俄 = 绿金 / 奥 = 白红）
- 兵种图标系统（步 / 骑 / 炮 / 海 / 将 / 事件）
- 闪卡 / 异画版本设计

### 六、商业化与首发策略（占 5%）

**1. 定价模型**
- F2P + 卡包（Kards 模式）vs 买断 + 卡包（昆特牌单机）vs 买断完整版（Inscryption 模式）
- Steam 平台玩家偏好：买断更受欢迎，但 CCG 长尾需要 F2P
- **推荐**：F2P + 创始人包（30-50 元）+ 战令

**2. 首发卡池规模**
- Kards 首发约 270 张，建议 MVP 200-280 张
- 核心法 / 英 / 普 / 俄 / 奥 五大阵营，每家 35-45 张 + 中立 30 张

**3. 赛季节奏**
- 3 个月 / 赛季，每赛季 40-60 张新卡
- 半年一次大扩展（如新增西班牙游击或海军主题）

---

### 七、技术与团队（占 5%）

- 引擎：Unity（CCG 主流，资产丰富） vs Godot（轻量但 CCG 案例少）
- 网络：Photon / Mirror / 自建专用服务器
- 卡牌脚本：JSON/YAML 数据驱动 + Lua 行为脚本（参考 Slay the Spire Mod 架构）
- 反作弊：服务端权威 + 简单加密足够（CCG 不像 FPS 需要重型反作弊）
- 团队规模建议：MVP 阶段 8-15 人（策划 2 / 程序 4 / 美术 3-5 / QA 1 / 制作人 1）
